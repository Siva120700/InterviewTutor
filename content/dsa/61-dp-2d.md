## Why this matters

2D DP covers grids and string alignments — frequent Medium/Hard territory.

## Definitions

- **2D DP:** Dynamic programming whose state is indexed by two dimensions (grid cell, two string prefixes, items×capacity).
- **Grid path DP:** Counting or optimizing paths on a matrix where each cell depends on neighbors (often up/left).
- **LCS (longest common subsequence):** The longest sequence appearing in both strings in order (not necessarily contiguous).
- **Edit distance (Levenshtein):** The minimum insertions, deletions, and substitutions to transform one string into another.
- **0/1 knapsack:** Choosing each item at most once to maximize value under a weight/capacity constraint.
- **Rolling array:** Keeping only the previous row (or a 1D array) when transitions only need recent layers — same answers, less space.
- **Iteration direction:** Loop order that enforces 0/1 vs unbounded reuse (backward vs forward capacity loops).

## Unique paths (grid)

```java
int uniquePaths(int m, int n) {
  int[] dp = new int[n];
  Arrays.fill(dp, 1);
  for (int i = 1; i < m; i++)
    for (int j = 1; j < n; j++) dp[j] += dp[j - 1];
  return dp[n - 1];
}
```

```csharp
int UniquePaths(int m, int n) {
  var dp = Enumerable.Repeat(1, n).ToArray();
  for (int i = 1; i < m; i++)
    for (int j = 1; j < n; j++) dp[j] += dp[j - 1];
  return dp[n - 1];
}
```

## LCS

`dp[i][j]` = LCS of `a[0..i)` and `b[0..j)`.

```java
int lcs(String a, String b) {
  int n = a.length(), m = b.length();
  int[][] dp = new int[n + 1][m + 1];
  for (int i = 1; i <= n; i++)
    for (int j = 1; j <= m; j++)
      dp[i][j] = a.charAt(i - 1) == b.charAt(j - 1)
        ? dp[i - 1][j - 1] + 1
        : Math.max(dp[i - 1][j], dp[i][j - 1]);
  return dp[n][m];
}
```

## Edit distance

```java
int minDistance(String a, String b) {
  int n = a.length(), m = b.length();
  int[][] dp = new int[n + 1][m + 1];
  for (int i = 0; i <= n; i++) dp[i][0] = i;
  for (int j = 0; j <= m; j++) dp[0][j] = j;
  for (int i = 1; i <= n; i++)
    for (int j = 1; j <= m; j++) {
      if (a.charAt(i - 1) == b.charAt(j - 1)) dp[i][j] = dp[i - 1][j - 1];
      else dp[i][j] = 1 + Math.min(dp[i - 1][j - 1], Math.min(dp[i - 1][j], dp[i][j - 1]));
    }
  return dp[n][m];
}
```

```csharp
int MinDistance(string a, string b) {
  int n = a.Length, m = b.Length;
  var dp = new int[n + 1, m + 1];
  for (int i = 0; i <= n; i++) dp[i, 0] = i;
  for (int j = 0; j <= m; j++) dp[0, j] = j;
  for (int i = 1; i <= n; i++)
    for (int j = 1; j <= m; j++)
      dp[i, j] = a[i - 1] == b[j - 1]
        ? dp[i - 1, j - 1]
        : 1 + Math.Min(dp[i - 1, j - 1], Math.Min(dp[i - 1, j], dp[i, j - 1]));
  return dp[n, m];
}
```

## 0/1 Knapsack

```java
int knapsack(int[] w, int[] val, int W) {
  int[] dp = new int[W + 1];
  for (int i = 0; i < w.length; i++)
    for (int cap = W; cap >= w[i]; cap--)
      dp[cap] = Math.max(dp[cap], dp[cap - w[i]] + val[i]);
  return dp[W];
}
```

**Critical:** iterate capacity **downward** so each item used once. Unbounded → upward.

## Interview Q&A

- **Q:** Space optimize LCS?
  **A:** Two rows O(min(n,m)) — mention if asked.
- **Q:** Knapsack vs coin change?
  **A:** Same family; 0/1 vs unbounded loop direction differs.

## Pitfalls

- Mixing 0/1 and unbounded loops  
- Index confusion on empty prefixes
