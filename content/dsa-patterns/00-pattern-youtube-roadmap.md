## Why this matters

Templates alone are not enough. You need **pattern → 5–10 problems → video when stuck**. This lesson is the master index; each pattern lesson also has its own short list.

## How to use (daily loop)

1. Open one pattern lesson (template + cues)  
2. Attempt the **Easy** problem cold (20–25 min)  
3. If stuck → watch the matching YouTube video **after** your attempt  
4. Re-code from memory the same day  
5. Do 2–3 Mediums for that pattern before moving on  

```text
Attempt → (optional) Video → Re-code → Next problem
Never: Video first, then copy
```

## Interview Q&A

- **Q:** NeetCode or Striver?  
  **A:** NeetCode for fast pattern + English explainers; Striver for exhaustive A2Z depth. Many people use **NeetCode 150 order** and Striver when a topic feels weak.
- **Q:** Watch every video?  
  **A:** No — attempt first; watch only when stuck >20–25 min or after WA.
- **Q:** Java/C# but videos in Python/C++?  
  **A:** Fine — translate the template; our pattern lessons already give Java/C#.

## Pitfalls

- Binge-watching without coding  
- Jumping patterns every day (no depth)  
- Memorizing solutions instead of cues → template

“I study DSA pattern-wise: learn the template, solve a fixed problem list easy→hard, and use NeetCode / Striver / Aditya Verma videos only after attempting. That builds recognition speed for interviews.”
